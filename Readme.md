# Udon Image Loader
Simple prefab to load images ingame.

## Restrictions
This script is limited to what [VRChat's API allows in terms of image download and display](https://creators.vrchat.com/worlds/udon/image-loading/#before-you-begin).  
The most important restrictions to know would be :
- Images can be of maximum of 2048*2048 pixels.
- Maximum of one image every five seconds.
- Users need to allow untrusted URLs if they want to be able to upload or see images that doesn't comes from VRChat's allowed list of domains
